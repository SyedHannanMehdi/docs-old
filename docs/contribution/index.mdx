# Contributing to tscircuit

Welcome! tscircuit is an open-source project and we love contributions of all kinds — bug fixes, new features, documentation improvements, and more.

- **[Repository Overview](./repository-overview)** — Learn about the different tscircuit repos and what each one does. This is the best starting point for understanding where to contribute.

## Contribution Principles

- **TypeScript everywhere** — All tscircuit packages are written in TypeScript. Use strict types; avoid `any`.
- **Test-driven** — Add tests for every bug fix and new feature.
- **Small PRs** — Keep pull requests focused on a single change for easier review.
- **circuit-json is the contract** — When in doubt, changes should conform to the `circuit-json` specification.
