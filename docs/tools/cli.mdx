# CLI — `tsci`

The **tscircuit CLI** (`tsci`) is a command-line tool for developing, previewing, and publishing circuits from your local machine.

## Installation

```bash
npm install -g tscircuit tsx
```

After installation the `tsci` command is available globally. Run `tsci --help` to see all available commands.

## Key Commands

### `tsci init`

Bootstraps a new tscircuit project in the current directory.

```bash
mkdir my-circuit && cd my-circuit
tsci init
```

Generated project layout:

```
my-circuit/
├── README.md
├── examples/
│   └── MyExample.tsx
├── index.ts
├── lib/
│   └── MyCircuit.tsx
├── package.json
└── tsconfig.json
```

### `tsci dev`

Starts a local development server with a live-reloading circuit preview.

```bash
tsci dev
```

Opens a browser window at `http://localhost:3020` showing a Schematic and PCB view. Every file inside the `examples/` directory is listed as a selectable example.

### `tsci build`

Compiles your circuit and generates output files (Gerber, BOM, etc.) into a `dist/` folder.

```bash
tsci build
```

### `tsci publish`

Publishes your circuit to the [tscircuit registry](https://tscircuit.com/trending) so others can import and use it.

```bash
tsci publish
```

You must be logged in (`tsci login`) before publishing.

### `tsci login`

Authenticates your local machine with your tscircuit.com account.

```bash
tsci login
```

## Configuration

Project configuration lives in `package.json` under the `"tscircuit"` key (or a `tscircuit.config.ts` file for advanced setups). The `tsconfig.json` in your project is pre-configured to resolve tscircuit types.
