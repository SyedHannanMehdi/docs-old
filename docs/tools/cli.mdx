# CLI (`tsci`)

The `tsci` command-line interface is the primary tool for developing tscircuit
projects locally. It provides a live-preview dev server, project scaffolding,
package management, and export utilities.

## Installation

```bash
npm install -g tscircuit tsx
```

The `tsx` package is a TypeScript runner required to execute `.tsx` circuit
files on Node.js.

Verify the installation:

```bash
tsci --help
```

## Commands

### `tsci init`

Scaffold a new circuit project in the current directory.

```bash
mkdir my-circuit && cd my-circuit
tsci init
```

Generated project structure:

```
├── README.md
├── examples/
│   └── MyExample.tsx
├── index.ts
├── lib/
│   └── MyCircuit.tsx
├── package.json
└── tsconfig.json
```

### `tsci dev`

Start the local development server with a live PCB and schematic preview.

```bash
tsci dev
```

Opens `http://localhost:3020` in your browser. Every file saved in the
`examples/` directory is hot-reloaded automatically.

:::tip
Double-click anywhere inside the PCB Viewer to read the cursor coordinates —
useful when setting `pcb_x` / `pcb_y` props.
:::

### `tsci add`

Install a component from the tscircuit registry into your project.

```bash
tsci add @tscircuit/battery @tscircuit/a555timer
```

This fetches the package from the registry and adds it to `package.json`.

### `tsci publish`

Publish your circuit to the tscircuit registry so others can install it.

```bash
tsci publish
```

You must be logged in (`tsci login`) before publishing.

### `tsci export`

Export your circuit to various manufacturing or EDA formats.

```bash
# Gerber files (zip) — upload to JLCPCB, PCBWay, MacroFab, etc.
tsci export gerbers

# KiCad project
tsci export kicad

# SVG render
tsci export svg
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `TSCIRCUIT_REGISTRY` | Override the registry URL (default: `https://registry.tscircuit.com`) |
