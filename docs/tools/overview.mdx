# tscircuit Tools Overview

The tscircuit ecosystem is made up of several user-facing tools that work together to help you design, preview, convert, and manufacture circuits using TypeScript and React.

| Tool | Description | Link |
|------|-------------|------|
| [tscircuit.com / Runframe](./runframe) | Browser-based circuit playground & runner | [tscircuit.com](https://tscircuit.com) |
| [CLI (`tsci`)](./cli) | Command-line interface for local development | [npm](https://www.npmjs.com/package/tscircuit) |
| [PCB Viewer](./pcb-viewer) | Interactive PCB visualization component | [GitHub](https://github.com/tscircuit/pcb-viewer) |
| [Schematic Viewer](./schematic-viewer) | Interactive schematic visualization component | [GitHub](https://github.com/tscircuit/schematic-viewer) |
| [Autorouting.com](./autorouting) | Cloud-based PCB auto-router service | [autorouting.com](https://autorouting.com) |
| [Registry](./registry) | Publish and share reusable circuit components | [tscircuit.com/trending](https://tscircuit.com/trending) |
| [Converters](./converters) | Convert between circuit formats (KiCad, Gerber, etc.) | [GitHub](https://github.com/tscircuit) |
| [Core (`@tscircuit/core`)](./core) | The React-based circuit rendering engine | [GitHub](https://github.com/tscircuit/core) |

Each tool is documented in detail in its own page. Use the sidebar to navigate between them.
