# tscircuit Tools Overview

tscircuit provides a rich set of tools that work together to help you design,
preview, route, convert, and manufacture printed circuit boards using TypeScript
and React. This section covers each tool in depth.

## Tool Summary

| Tool | What it does | Where to find it |
|------|-------------|-----------------|
| [tscircuit.com / Runframe](./runframe) | Browser-based circuit editor & preview | [tscircuit.com](https://tscircuit.com) |
| [CLI (`tsci`)](./cli) | Local development server, project scaffolding, publishing | npm / terminal |
| [PCB Viewer](./pcb-viewer) | Interactive 2-D PCB renderer | embedded in runframe & npm |
| [Schematic Viewer](./schematic-viewer) | Interactive schematic renderer | embedded in runframe & npm |
| [Autorouter (autorouting.com)](./autorouter) | Automatic PCB trace routing | [autorouting.com](https://autorouting.com) |
| [Core (`@tscircuit/core`)](./core) | React rendering engine that converts JSX to Circuit JSON | npm |
| [Converters](./converters) | Export/import between Circuit JSON, Gerber, KiCad, STEP, etc. | CLI & npm |

Each tool page explains the purpose of the tool, how to install or access it,
and how it fits into a typical tscircuit workflow.
