# tscircuit Tools Overview

tscircuit ships a collection of tightly-integrated tools that take you from
writing TypeScript circuit code all the way to manufacturing-ready Gerber files.
This page gives you a bird's-eye view of each tool and when to reach for it.

| Tool | Where to use it | What it does |
|---|---|---|
| [tscircuit.com / Runframe](./runframe) | Browser | Live preview, share & publish circuits |
| [CLI (`tsci`)](./cli) | Terminal | Init, dev server, build & publish from the command line |
| [PCB Viewer](./pcb-viewer) | Browser / embedded | Interactive PCB rendering and inspection |
| [Autorouter (autorouting.com)](./autorouter) | Browser / API | Automatically route traces on a PCB |
| [Format Converters](./format-converters) | CLI / API | Convert Circuit JSON to Gerber, KiCad, SVG, STEP & more |
| [Core (`@tscircuit/core`)](./core) | npm package | React-based circuit rendering engine |

Pick the section that matches what you want to do, or start with the
[Quickstart](/quickstart) if you are brand new to tscircuit.
