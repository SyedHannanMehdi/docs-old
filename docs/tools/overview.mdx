# tscircuit Tools Overview

The tscircuit ecosystem is made up of several user-facing tools that cover every
stage of the circuit design workflow — from writing and previewing circuit code to
autorouting, exporting, and converting files. This page gives you a quick map of
every tool so you can jump straight to the one you need.

| Tool | Purpose | Where to find it |
|---|---|---|
| [tscircuit.com / Runframe](./runframe) | Browser-based circuit playground & registry | [tscircuit.com](https://tscircuit.com) |
| [CLI (`tsci`)](./cli) | Local dev server, init, publish | `npm i -g tscircuit` |
| [PCB Viewer](./pcb-viewer) | Interactive PCB preview component | [npm: @tscircuit/pcb-viewer](https://www.npmjs.com/package/@tscircuit/pcb-viewer) |
| [Autorouter (autorouting.com)](./autorouter) | Cloud & local autorouting service | [autorouting.com](https://autorouting.com) |
| [Core (`@tscircuit/core`)](./core) | React renderer that converts JSX → Circuit JSON | [GitHub](https://github.com/tscircuit/core) |
| [File Converters](./converters) | Convert Circuit JSON to Gerber, KiCad, BOM, etc. | Various packages |

Pick any tool from the sidebar to read its full documentation.
