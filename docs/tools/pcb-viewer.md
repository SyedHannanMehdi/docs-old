# PCB Viewer

The **tscircuit PCB Viewer** is an interactive, browser-based viewer for PCB layouts generated by tscircuit. It supports both 2D and 3D visualization and is embedded directly in the tscircuit web editor, the `tsci dev` server, and Runframe.

## Where to Use It

| Context | How to access |
|---------|---------------|
| Web editor | [tscircuit.com](https://tscircuit.com) — built in |
| Local dev server | Run `tsci dev`, open `http://localhost:3000` |
| Runframe | [runframe.tscircuit.com](https://runframe.tscircuit.com) |
| React app | Install the npm package (see below) |

## Features

- **2D PCB view** — top-down view of copper layers, silkscreen, courtyard, and drill holes
- **3D PCB view** — extruded 3D render of the board with component outlines
- **Schematic view** — view the schematic diagram generated from the same circuit code
- **Layer visibility toggles** — show/hide individual copper layers (F.Cu, B.Cu), silkscreen, courtyard, etc.
- **Zoom & pan** — smooth mouse-wheel zoom and click-drag panning
- **Component hover** — hover over a footprint to highlight it and see component metadata
- **Error highlighting** — DRC (design rule check) violations are highlighted directly on the board

## Embedding the PCB Viewer in a React App

The PCB Viewer is available as a standalone React component:

```bash
npm install @tscircuit/pcb-viewer
```

```tsx
import { PCBViewer } from "@tscircuit/pcb-viewer"

export default function App() {
  // `soup` is the tscircuit circuit JSON produced by tscircuit/core
  return (
    <PCBViewer
      soup={circuitJson}
      style={{ width: "100%", height: "600px" }}
    />
  )
}
```

### Props

| Prop | Type | Description |
|------|------|-------------|
| `soup` | `AnySoupElement[]` | Circuit JSON (output of tscircuit/core) |
| `style` | `React.CSSProperties` | Container style |
| `className` | `string` | Container CSS class |
| `initialLayer` | `"top" \| "bottom"` | Which copper layer to show first |
| `onHoverElement` | `(el) => void` | Callback when user hovers an element |
