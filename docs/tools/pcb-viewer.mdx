# PCB Viewer

The **PCB Viewer** is an interactive React component that renders a PCB layout from tscircuit's internal circuit JSON (`soup`) format. It is used inside the tscircuit playground and the local `tsci dev` preview server.

## Features

- Renders copper traces, pads, vias, silkscreen, board outline, and drill holes
- Pan and zoom with mouse/touch
- Hover over components to inspect properties
- Toggle individual PCB layers on/off
- Highlights rats-nest (unrouted connections)

## Installation

```bash
npm install @tscircuit/pcb-viewer
```

## Usage

```tsx
import { PCBViewer } from "@tscircuit/pcb-viewer"

export default function App() {
  const circuitJson = [/* your circuit JSON soup */]

  return (
    <div style={{ width: 800, height: 600 }}>
      <PCBViewer circuitJson={circuitJson} />
    </div>
  )
}
```

### Props

| Prop | Type | Description |
|------|------|-------------|
| `circuitJson` | `AnySoupElement[]` | The circuit JSON (soup) to render |
| `height` | `number` | Optional height override in pixels |
| `initialState` | `object` | Optional initial pan/zoom/layer state |
| `onHoverElement` | `(el) => void` | Callback when the user hovers over an element |

## Where It's Used

| Context | How |
|---------|-----|
| [tscircuit.com](https://tscircuit.com) | PCB tab in the playground |
