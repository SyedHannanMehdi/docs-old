# Runframe & tscircuit.com

[tscircuit.com](https://tscircuit.com) is the hosted platform built on top of
**Runframe** — an open-source, browser-based circuit runner that evaluates
your TypeScript/TSX circuit code entirely in the browser and renders an
interactive schematic and PCB preview in real time.

## What is Runframe?

[`runframe`](https://github.com/tscircuit/runframe) is the open-source React
component at the heart of tscircuit.com. It:

- Compiles and evaluates TSX circuit code **inside a Web Worker** using an
  in-browser TypeScript bundler, so nothing needs to be installed.
- Renders the **schematic view** and **PCB view** side-by-side.
- Shows build errors inline with a code editor.
- Supports importing packages from the tscircuit registry on the fly.

You can embed Runframe in your own app — see the
[runframe GitHub repository](https://github.com/tscircuit/runframe) for
installation and embedding instructions.

## Using tscircuit.com

### Create a snippet

1. Go to [tscircuit.com](https://tscircuit.com).
2. Click **New** (no sign-up required for anonymous snippets).
3. Write or paste your circuit TSX in the code editor on the left.
4. The preview updates automatically as you type.

### Share a circuit

Every snippet gets a unique URL. Share that URL with teammates or embed it in
a pull request or issue.

### Publish to the registry

Log in with GitHub, then click **Publish**. Your circuit becomes available on
the [tscircuit registry](https://tscircuit.com/trending) so others can install
it with:

```bash
tsci add @your-username/your-circuit
```

## Runframe Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl/Cmd + S` | Force re-run the circuit |
| `Scroll` | Zoom in/out on the viewer |
| `Click + drag` | Pan the viewer |

## Embedding Runframe

```bash
npm install @tscircuit/runframe
```

```tsx title="App.tsx"
import { RunFrame } from "@tscircuit/runframe"

export default function App() {
  return (
    <RunFrame
      code={`
export default () => (
  <resistor name="R1" resistance="10kohm" footprint="0402" />
)
      `}
    />
  )
}
```
