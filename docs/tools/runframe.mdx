# Runframe

**Runframe** is the browser-based circuit runner and playground built into [tscircuit.com](https://tscircuit.com). It lets you write, run, and preview tscircuit code without installing anything locally.

## What It Does

- Compiles and executes TypeScript/TSX circuit code in the browser using a web worker
- Renders an interactive **Schematic** and **PCB** preview side-by-side
- Supports importing packages from the tscircuit registry
- Exports your design to files (Gerber, BOM, Pick-and-Place, etc.)

## How to Use

1. Go to [tscircuit.com](https://tscircuit.com)
2. Click **"New"** in the top navigation — no sign-up required
3. Write or paste your circuit code in the editor on the left
4. The schematic and PCB views update automatically as you type

```tsx
import { Led, Resistor } from "@tsci/seveibar.smd-led"

export default () => (
  <board width="10mm" height="10mm">
    <Led name="LED1" />
    <Resistor name="R1" resistance="100ohm" footprint="0402" />
  </board>
)
```

## Sharing Circuits

Every circuit you save is published to the **registry** and gets a unique URL that you can share with others. Saved circuits are visible on your profile page.

## Running Locally with `@tscircuit/runframe`

Runframe is also available as a standalone React component / Electron app for local development:

```bash
npm install @tscircuit/runframe
```

- **GitHub**: [github.com/tscircuit/runframe](https://github.com/tscircuit/runframe)
- It is also what powers the `tsci dev` local preview server (see [CLI](./cli)).
